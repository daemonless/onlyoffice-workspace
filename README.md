Self-hosted collaborative office workspace combining Documents, Projects, CRM, Mail, Calendar, People, Control Panel, and real-time ONLYOFFICE Document Server editors.

This is the full **ONLYOFFICE Workspace** portal (users, Documents, Projects, CRM, Calendar, People, and Control Panel), with Document Server included by default. If you already run Nextcloud, Seafile, or OwnCloud and only want the standalone document editors to connect to it, see **[ONLYOFFICE Document Server](https://daemonless.io/images/onlyoffice/)** (`daemonless/onlyoffice`) instead.

## Deployment

### Podman Compose

**Database.** Where ONLYOFFICE Workspace keeps its portal data. The default runs its own MariaDB.

**Document editors.** Online collaborative editors for Word, Excel and PowerPoint files inside Documents.

#### Built-in MariaDB, With Document Server (Workspace) (default)

A MariaDB of its own, on the stack's private network. Runs ONLYOFFICE Document Server and its PostgreSQL alongside the portal.

**1.** Save as `.env` and fill in what is empty:

```env { data-zip-bundle="onlyoffice-workspace-podman" data-zip-filename=".env" }
WORKSPACE_DATA_LOCATION=/containers/onlyoffice-workspace/data
DOCSERVER_DATA_LOCATION=/containers/onlyoffice-workspace/docserver
MARIADB_DATA_LOCATION=/containers/onlyoffice-workspace/mariadb
POSTGRES_DATA_LOCATION=/containers/onlyoffice-workspace/postgres
DB_PASSWORD=
DB_ROOT_PASSWORD=
JWT_SECRET=
CORE_MACHINEKEY=
TZ=UTC
```

**2.** Save as `compose.yaml`:

```yaml { data-zip-bundle="onlyoffice-workspace-podman" data-zip-filename="compose.yaml" }
name: onlyoffice-workspace

services:
  onlyoffice-workspace:
    image: ghcr.io/daemonless/onlyoffice-workspace:${ONLYOFFICE_WORKSPACE_TAG:-latest}
    container_name: onlyoffice-workspace
    network_mode: host
    restart: unless-stopped
    annotations:
      org.freebsd.jail.allow.mlock: "true"
    depends_on:
      - mariadb
      - onlyoffice-documentserver
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=${TZ:-UTC}
      - HTTP_PORT=8080
      - MYSQL_SERVER_HOST=${MARIADB_HOSTNAME:-127.0.0.1}
      - MYSQL_SERVER_PORT=${MARIADB_PORT:-3306}
      - MYSQL_SERVER_DB_NAME=${MARIADB_DATABASE:-onlyoffice}
      - MYSQL_SERVER_USER=${MARIADB_USER:-onlyoffice}
      - MYSQL_SERVER_PASS=${DB_PASSWORD}
      - MYSQL_SERVER_ROOT_PASS=${DB_ROOT_PASSWORD:-}
      - DOCUMENT_SERVER_HOST=${DOCUMENT_SERVER_HOSTNAME-127.0.0.1}
      - DOCUMENT_SERVER_PORT=8083
      - JWT_ENABLED=true
      - JWT_SECRET=${JWT_SECRET}
      - JWT_HEADER=AuthorizationJwt
      - CORE_MACHINEKEY=${CORE_MACHINEKEY:-}
    volumes:
      - ${WORKSPACE_DATA_LOCATION}:/config

  onlyoffice-documentserver:
    image: ghcr.io/daemonless/onlyoffice:pkg
    container_name: onlyoffice-documentserver
    network_mode: host
    restart: unless-stopped
    depends_on:
      - postgres
    environment:
      - DB_HOST=${POSTGRES_HOSTNAME:-127.0.0.1}
      - DB_PORT=5432
      - DB_NAME=onlyoffice
      - DB_USER=onlyoffice
      - DB_PWD=${DB_PASSWORD}
      - HTTP_PORT=8083
      - JWT_ENABLED=true
      - JWT_SECRET=${JWT_SECRET}
      - JWT_HEADER=AuthorizationJwt
      - TZ=${TZ:-UTC}
    volumes:
      - ${DOCSERVER_DATA_LOCATION}:/config

  mariadb:
    image: ghcr.io/daemonless/mariadb:latest
    container_name: onlyoffice-mariadb
    network_mode: host
    restart: unless-stopped
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=${TZ:-UTC}
      - MYSQL_ROOT_PASSWORD=${DB_ROOT_PASSWORD}
      - MYSQL_DATABASE=onlyoffice
      - MYSQL_USER=onlyoffice
      - MYSQL_PASSWORD=${DB_PASSWORD}
    volumes:
      - ${MARIADB_DATA_LOCATION}:/config

  postgres:
    image: ghcr.io/daemonless/postgres:16
    container_name: onlyoffice-postgres
    network_mode: host
    restart: unless-stopped
    annotations:
      org.freebsd.jail.allow.sysvipc: "true"
    environment:
      - POSTGRES_DB=onlyoffice
      - POSTGRES_USER=onlyoffice
      - POSTGRES_PASSWORD=${DB_PASSWORD}
      - POSTGRES_HOST_AUTH_METHOD=trust
    volumes:
      - ${POSTGRES_DATA_LOCATION}:/var/lib/postgresql/data
```

Then run `podman-compose up -d`.

## Setup Instructions

**Modules not included.** External CalDAV/CardDAV sync (Radicale) is not included; the built-in Calendar and People modules work without it. The Mail module (external IMAP/SMTP aggregation) is not included yet.

## Parameters

### Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `PUID` | `1000` | User ID for the application process |
| `PGID` | `1000` | Group ID for the application process |
| `TZ` | `UTC` | Timezone for the containers |
| `HTTP_PORT` | `8080` | HTTP listen port for the Workspace portal (default: 8080) |
| `MYSQL_SERVER_HOST` | `127.0.0.1` | MariaDB server hostname |
| `MYSQL_SERVER_PORT` | `3306` | MariaDB server port (default: 3306) |
| `MYSQL_SERVER_DB_NAME` | `onlyoffice` | MariaDB database name (default: onlyoffice) |
| `MYSQL_SERVER_USER` | `onlyoffice` | MariaDB username (default: onlyoffice) |
| `MYSQL_SERVER_PASS` | `<MYSQL_SERVER_PASS>` | MariaDB password |
| `MYSQL_SERVER_ROOT_PASS` | `<MYSQL_SERVER_ROOT_PASS>` | MariaDB root password for applying global sql_mode and max_allowed_packet settings at startup |
| `DOCUMENT_SERVER_HOST` | `${DOCUMENT_SERVER_HOSTNAME-127.0.0.1}` | Document Server hostname |
| `DOCUMENT_SERVER_PORT` | `8083` | Document Server HTTP port (default: 8083) |
| `JWT_ENABLED` | `true` | Enable JWT validation with Document Server (default: true) |
| `JWT_SECRET` | `<JWT_SECRET>` | Shared JWT secret between Workspace and Document Server |
| `JWT_HEADER` | `AuthorizationJwt` | JWT HTTP header name (default: AuthorizationJwt) |
| `CORE_MACHINEKEY` | `<CORE_MACHINEKEY>` | Portal encryption and token signing key (generated and persisted on first start if unset) |
| `WORKSPACE_DATA_LOCATION` | `/containers/onlyoffice-workspace/data` | Path to store ONLYOFFICE Workspace portal data, uploads, and logs |
| `DOCSERVER_DATA_LOCATION` | `/containers/onlyoffice-workspace/docserver` | Path to store Document Server cache and data |
| `MARIADB_DATA_LOCATION` | `/containers/onlyoffice-workspace/mariadb` | Path to store MariaDB database files |
| `POSTGRES_DATA_LOCATION` | `/containers/onlyoffice-workspace/postgres` | Path to store PostgreSQL database files |
| `DB_PASSWORD` | `<DB_PASSWORD>` | Database password for MariaDB and PostgreSQL |
| `DB_ROOT_PASSWORD` | `<DB_ROOT_PASSWORD>` | MariaDB root password (built-in MariaDB only) |
| `MARIADB_HOSTNAME` | `` | Where the portal finds MariaDB (fjord sets this for the built-in one; 127.0.0.1 on host networking) |
| `MARIADB_PORT` | `` | MariaDB port (your own MariaDB) |
| `MARIADB_DATABASE` | `` | Database name (your own MariaDB) |
| `MARIADB_USER` | `` | Database user (your own MariaDB) |
| `POSTGRES_HOSTNAME` | `` | Where Document Server finds PostgreSQL (fjord sets this; 127.0.0.1 on host networking) |
| `DOCUMENT_SERVER_HOSTNAME` | `` | Where the portal finds Document Server (127.0.0.1 on host networking; empty disables online editors) |

### Volumes

| Path | Description |
|------|-------------|
| `/config` | Persistent portal data, uploads, certificates, and logs |

**Architectures:** amd64
**User:** `bsd` (UID/GID via PUID/PGID, defaults to 1000:1000)
**Base:** FreeBSD 15
